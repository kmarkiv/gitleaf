GitLeaf v0.3.6 brings the tested Rust backend improvements to the downloadable Mac app and Windows/Linux executables.

### What changed

- Downloads, release checks and Tectonic installation now run in Rust. GitLeaf no longer needs system curl or tar for these operations.
- Downloads reuse network connections, stream to disk and verify SHA-256 checksums with size limits. Failed downloads preserve the previous file.
- Rust classifies generated files and detects the main LaTeX document. Opening a nonstandard main document avoids repeated browser file-content requests.
- Compiler extraction reads only a regular executable from TAR.GZ or ZIP; linked or duplicate compiler executables are refused.
- Setup documentation now reflects the built-in download tools and retains guidance for older releases.

### Downloads and upgrading

Use the Mac DMG for Apple silicon or Intel, or the standalone executable for Windows or Linux. Mac users should wait for **Saved**, quit through the leaf menu, then replace GitLeaf.app in Applications. Standalone executables support the toolbar updater. Your papers remain in their projects folder.

Git is still required. Offline compilation needs a compiler and every required package already installed or cached. Mac packages are not yet notarized and may need first-launch approval. Release asset checksums are provided in SHA256SUMS.txt.

The optimization commit passed Windows, Linux and macOS CI, including RustSec checks. Local validation covered 55 Rust tests, 4 JavaScript tests, offline browser regressions, verified Tectonic installation without curl/tar, real LaTeX and SyncTeX, and native Mac startup/Quit.
